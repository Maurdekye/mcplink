# Resonite Data Model

> Resonite engine data-model and component reference (ILSpy-verified) — Slot hierarchy/persistence/ordering/destroy internals, RefID layout, sync members (Sync/SyncRef/AssetRef/SyncObject), drives and links, dynamic variables, plus UIX/physics/data-feed/inventory data-model details.

## FrooxEngine data-model reference (ILSpy-verified, Build 2026.6.x)

Ground-truth internals for reading source / predicting engine behavior. Complements §4's data-model summary.

### Slot internals (`FrooxEngine.Slot`)
- **Transform writes self-sanitize, never error.** `PositionFilter` returns `float3.Zero` on NaN/Inf; `ScaleFilter` returns `float3.One`; `RotationFilter` returns `value.FastNormalized` if valid else `floatQ.Identity` — so bad values snap to safe defaults silently. `GlobalRotation` setter only applies if `value.IsValid` (applies `FastNormalized`); `GlobalScale` setter only if `!IsNaN && !IsInfinity`. (`Slot.PositionFilter`/`RotationFilter`/`ScaleFilter`/`GlobalRotation`/`GlobalScale`)
  - **⚠️ Correction (live-verified, Build 2026.6.19):** rotations are NOT "always normalized on write". `floatQ.IsValid` is `0.9 < SqrMagnitude < 1.1`, so a rotation write whose quaternion isn't *already* near-unit is reset to `floatQ.Identity`, **not** normalized (`FastNormalized` only cleans sub-2.1e-8 drift). Confirmed live: `(1,1,1,1)`→Identity, `(0,0.7071,0,0.7071)`→unchanged. Always feed an already-normalized quaternion. See the `reso-transforms-math` skill.
- **Root slot is locked.** Position/Rotation/Scale/Active/Persistent filters *throw* on any non-identity / false value ("Cannot change … of the Root Node"). `GlobalRotationToLocal`/`GlobalScaleToLocal` short-circuit to identity passthrough when `IsRootSlot`. (`Slot.Root*Filter`)
- **Sibling order = `OrderOffset` (`Sync<long>`, Int64) then `ReferenceID` tiebreaker** — equal offsets sort by creation/RefID (newer after older). `MakeSpaceForOrderNumber` appends at `prev+100` and inserts at the midpoint of the gap (recursively pushing siblings if gap ≤1) — ~100 of headroom per sibling for cheap reordering. (`Slot.ChildComparison`/`OrderOffset_Field`/`MakeSpaceForOrderNumber`)
- **`ChildIndex` setter SWAPS, not inserts** — it exchanges this slot's order with the slot currently at `value` (`SwapChildren`), throws if `value >= ChildrenCount`. To truly insert use `InsertSlot`/`InsertAtIndex`. The `this[int]` indexer and `Children` call `EnsureChildOrder()` first (order is lazily validated); indexer throws on out-of-range. (`Slot.ChildIndex`/`get_Item`)
- **`IsActive`/`IsPersistent` are cached AND-up-the-chain flags**, not live walks: `IsActive => _activeInHierarchy` = this `ActiveSelf` AND every ancestor active; `IsPersistent => _persistentInHierarchy` likewise from `PersistentSelf`. Recomputed event-driven (`UpdateActiveHierarchy`/`UpdatePersistenceHierarchy`); `SendActivatedEvents` defers off-thread via `UpdateManager`. Separate gates: `IsProtected` (via `MarkProtected`), `ForcedPersistent`. (`Slot.get_IsActive`/`get_IsPersistent`)
- **`AddSlot` defaults `persistent=true`, name `"Slot"`; `AddLocalSlot` defaults `persistent=false`.** Both throw if the slot is already removed; `AddSlot` routes to `World.AddLocalSlot` when the slot `IsLocalElement`. (`Slot.AddSlot`/`AddLocalSlot`)
- **`SetParent`/`Duplicate` default `keepGlobalTransform=true`.** `SetParent`: null→`RootSlot`, removed parent→warn+`RootSlot`, reparenting under own descendant silently ignored; when keeping global transform with driven T/R/S fields it decomposes and writes each component, **skipping any `IsBlockedByDrive` field** (won't fight a drive); no-op if `IsProtected`. `Duplicate` throws on root, defaults `duplicateRoot=Parent`, runs `IDuplicationHandler.OnBeforeDuplicate` + `Component.RunDuplicate` per component. (`Slot.SetParent`/`Duplicate`)
- **Destroy semantics.** `Destroy()`/`DestroyPreservingAssets()` are `[SyncMethod]` (networked); throw on root; early-out if `IsProtected` or already destroyed. `Destroy(Slot moveChildren)` reparents children first via `ReparentChildren` (throws if target `IsChildOf(this, includeSelf:true)`) then `DestroySelf`. In `DestroyChildren`, a **protected child is reparented to root (`Parent=null`) instead of destroyed**. `DestroyPreservingAssets` relocates asset components to a new `<Name> - Assets` slot under `World.AssetsSlot`. `PrepareDestruction` fires `OnPrepareDestroy` **before** detaching from parent. (`Slot.Destroy`/`DestroyChildren`/`PrepareDestruction`)
- **Search/depth helpers.** `FindChild(string)` is exact-match, ordinal, **immediate children only, no recursion**; use `FindChildInHierarchy(name)` (recursive DFS) or `FindChild(name, matchSubstring, ignoreCase, maxDepth)`. `IsChildOf` cycle-guard is the originator check (`Parent==originator`), not the unused `max=255` counter. `ComputeHierarchyDepth(root)` returns **-1 if `root` is not an ancestor**; `HierachyDepth` recomputes (uncached) each access. (`Slot.FindChild`/`IsChildOf`/`ComputeHierarchyDepth`)
- **`ActiveUser`** derives from `ActiveUserRoot?.ActiveUser`; **there is no `Slot.GetAllocatingUser`** — it's the extension `WorldElementExtensions.GetAllocatingUser(this IWorldElement)`. (`Slot.ActiveUser`)

### `RefID` (`Elements.Core.RefID`)
One readonly `ulong`: `Construct(position,user) = (position<<8)|(user&0xFF)` — **low 8 bits = user index, high 56 = allocation position**. `USER_BITS=8`, `USER_MASK=0xFF`, `MAX_USERS=255`, `LOCAL_ID=255` (`IsLocalID` when user byte==255). `ToString() = "ID"+hex` (uppercase); `TryParse` expects that form. **`CompareTo` sorts by user first then position** (not raw ulong — `RawCompareTo` does raw). This is the Reso-side raw id; the MCP's `Reso_XXXX` is a separate abstraction.

### Sync members
- **`SyncRef<T>`**: has `State` (`ReferenceState`), `RawTarget`, `Target`, `Value` (`RefID`), `IsTargetRemoved`, and **three distinct events** — `OnReferenceChange` (RefID changed), `OnObjectAvailable` (target became resolvable), `OnTargetChange`. `TrySet` returns false (no throw) if not assignable to `T`. Driven-ref writes blocked like fields. (`SyncRef\`1`)
- **`AssetRef<A>`**: a `SyncRef` whose `Target` is `IAssetProvider`; exposes `Asset`, `IsAssetAvailable`, and **`ListenToAssetUpdates` (bool)** controlling whether it re-fires when the underlying asset (e.g. texture finishing load) updates. (`AssetRef\`1`)
- **`SyncObject`** (compound nested-struct members) is a `SyncElement`, **not a `Worker`**: has `OnAwake`/`InitializeSyncMembers`/link-drive members but **no `OnInit`/`OnStart`/`OnChanges`/`OnDestroy`** — those lifecycle hooks are Worker/Component-only. (`SyncObject`)

### Drives & links (`LinkBase<T>`, driver components)
- **A field can have only ONE driver/link** — this is the mechanical basis of `IsDriven`. `TryLink` returns false if `target.IsLinked`; `ForceLink` releases the prior `DirectLink` first. Setting `Target` on an already-linked element warns and suggests `ForceLink`. `IsLinkValid` requires `State==Available && IsLinkGranted && Target.ActiveLink==this`. (`LinkBase\`1.TryLink`/`ForceLink`/`IsLinkValid`)
- **Drive grant is asynchronous.** `SetValue` calls `World.LinkManager.RequestLink(this)` and sets `IsLinkGranted=false`; the grant arrives later via `GrantLink()`. So immediately after wiring a `FieldDrive`, `IsLinkValid` can be false until granted — don't assume a fresh drive is live the same frame. (`LinkBase\`1.SetValue`/`GrantLink`)
- **`ValueDriver<T>` polls every tick** (writes target in `OnCommonUpdate`, re-asserts continuously, writes `default(T)` when source null). **`ValueCopy`/`ValueMultiDriver`/`BooleanValueDriver`/`ValueGradientDriver`/`ReferenceCopy`/`ReferenceEqualityDriver` are event-driven** (`OnChanges`, only on input change) — a real perf/timing distinction. (`ValueDriver\`1` vs `ValueCopy\`1`)
- **`ValueCopy`/`ReferenceCopy` `WriteBack=true`** makes the copy bidirectional: writing the driven target also writes the source (via a set-hook), unless source is a `ConflictingSyncElement{DirectAccessOnly}`. (`ValueCopy\`1.OnAwake`)
- `ValueGradientDriver<T>` (requires `Coder<T>.SupportsLerp`): points sorted by `Position` (`[Range(0,1)]`); `Interpolate=true` → clamped `Coder<T>.Lerp` between bracketing points, else steps to lower point; 0 points → `default(T)`. `ValueMultiDriver<T>` broadcasts one value to a `SyncList<FieldDrive<T>>`. `BooleanValueDriver<T>` picks `TrueValue`/`FalseValue` by `State`. `ReferenceEqualityDriver<T>` drives a `bool` = (`TargetReference.Target.Target == Reference.Target`) XOR `Invert`. Driver generic validity gated by `Coder<T>.IsEnginePrimitive` (most) or `SupportsLerp` (gradient). (`*Driver\`1.OnChanges`/`IsValidGenericType`)

### Dynamic variables (`DynamicVariableSpace`, `DynamicVariableHelper`)
- **Keyed by `(Type, name)`** (`VariableIdentity` struct, equality on both) — a space can hold `"Foo"` as a float AND `"Foo"` as a color independently; `GetManager<T>`/`RegisterDynamicValue<T>` always include `typeof(T)`. (`DynamicVariableSpace.VariableIdentity`)
- **First-reader-wins linking.** On register, if a reader already exists and the new var does NOT set `OverrideOnLink`, the new var **adopts the existing value**; only the first reader (or `OverrideOnLink=true`) pushes its own value. Removing the last *readable* var resets the shared value to `Coder<T>.Default` (write-only vars don't count); the manager auto-disposes when the last var (any kind) unregisters. (`ValueManager\`1.Register`/`Unregister`)
- **Path parsing: only the FIRST `/` splits** space-name from variable-name — everything after the first slash is the variable name (may itself contain slashes). No slash → bare name, space resolved by proximity. (`DynamicVariableHelper.ParsePath`)
- **Name validation:** empty/whitespace counts as *valid*; otherwise rejects any `IsSymbol`/`IsPunctuation`/`IsWhiteSpace` char **except whitelisted `space`, `-`, `.`, `_`**. So `/`, `:`, `@`, `#` make a name invalid; `ProcessName` returns null for invalid names → the variable **silently binds to nothing**. Same rule applies to space `SpaceName` → `CurrentName=null`. (`DynamicVariableHelper.IsValidName`/`ProcessName`)
- **Space resolution walks up parents.** Bare-name vars bind to the nearest ancestor space whose **`OnlyDirectBinding.Value==false`** (so `OnlyDirectBinding=true` hides a space from un-namespaced vars — they must name it explicitly). A named lookup matches `CurrentName` and ignores `OnlyDirectBinding`. Vars **rebind live on any hierarchy change** (`OnHierarchyChanged`→`MarkSpaceDirty`→re-`FindSpace`), so reparenting re-targets them. (`DynamicVariableHelper.FindSpace`/`DynamicVariableHandler\`1.OnHierarchyChanged`)
- **`TryWriteValue<T>` → `DynamicVariableWriteResult{Success=0,NotFound=1,Failed=2}`**: `NotFound` when no manager or no reader holds it (write-only-only consumers); `Failed` when `IsValidValue` rejects. **Type-valued** dynvars validate against `World.Types.IsSupported` (unsupported `Type` → `Failed`); all other `T` accept anything. (`DynamicVariableSpace.TryWriteValue<T>`/`TypeValueManager`)
- **`DynamicValueVariableDriver<T>` is write-only** (reads a dynvar → drives a field; `IsWriteOnly=true`, doesn't publish, drives `DefaultValue` when var absent); contrast **`DynamicValueVariable<T>`** which is a readable+writable store. `DynamicField<T>` binds an arbitrary `IField<T>` to a dynvar but silently no-ops on non-writable/`DirectAccessOnly` targets. `DynamicValueVariableReset<T>`/`DynamicReferenceVariableReset` restore a value on `ResetOnLoad`/`ResetOnDuplicate`/`ResetOnPaste`. (`DynamicValueVariableDriver\`1`/`DynamicField\`1`)

### UIX internals (`FrooxEngine.UIX.*`)
- **`RectTransform` rect = anchors (fractional 0..1 of parent) + offsets (absolute px):** `FromMinMax(parent.pos + parent.size*AnchorMin + OffsetMin, … *AnchorMax + OffsetMax)`. Fresh `RectTransform` defaults to **full-stretch** (AnchorMin 0,0 / AnchorMax 1,1 / Offsets 0 / Pivot 0.5,0.5). Helpers: `SetProportional{Header,Footer,Left,Right}`, `SetFixed{Vertical,Horizontal,Rect}`, `AddFixedPadding(top,right,bottom,left)`. (`RectTransform.ComputeRect`/`OnAwake`)
- **`Canvas` is in pixels, design space `1920×1080` default** (PixelScale/UnitScale=1, `StartingOffset=-32000`); **world-unit size comes from the canvas root Slot's LocalScale, not the Canvas**. `OnAttach` attaches and *drives* a `BoxCollider` (Size/Offset via `FieldDrive`) — that's what makes it laser/touch-interactable; don't size it manually. (`Canvas.OnAwake`/`OnAttach`)
- **Layout is async + batched.** `Canvas.ComputeCanvasUpdate` runs a Task over dirty lists; `RectTransform` self-registers dirty and uses two flag enums (`DataModelFlag`/`ComputeFlag`) for incremental per-axis (`RunLayoutPass`) recompute. **Mutating rect fields does not lay out immediately** — changes batch into the next canvas update. `LayoutElement` overrides are nullable `Sync<float?>` (null=no override) resolved by `Priority` (higher wins). (`Canvas.ComputeCanvasUpdate`/`LayoutElement`)
- **`UIBuilder.Next`** auto-attaches a `LayoutElement` only when the parent is a layout (`rootIsLayout && !Style.SupressLayoutElement`), copying **only** the Min/Preferred/Flexible Width/Height metrics from `Style`; `UIStyle.Width/Height`/colors are consumed by the specific build methods (`Text`/`Button`), not here. `UIBuilder(Slot,w,h,scale)` sets Canvas.Size=(w,h) and root `LocalScale=One*scale`. `UIStyle` sentinels: metric fields default `-1` = unset. (`UIBuilder.SetupCurrentAsLayoutElement`/`UIStyle..ctor`)
- **`Button` fires synced `Pressed` (SyncDelegate) BEFORE the local `LocalPressed` C# event**, then `IButtonPressReceiver` slot events if `SendSlotEvents`. Full surface: six `Local*` events + six synced `SyncDelegate`s (Pressed/Pressing/Released/HoverEnter/Stay/Leave); `SimulatePress(duration, eventData)` triggers programmatically. (`Button.RunPressed`)
- **`Text` defaults differ from `UIStyle`:** `Text.Size=64` vs `UIStyle.TextAutoSizeMax=40`; `ParseRichText=true`, `Color=Black`, `LineHeight=0.8`. Substantive image fields (Sprite/Material/PreserveAspect/`NineSliceSizing{FixedSize,TextureSize,RectWidth,RectHeight}`/Flip) live on **`ImageBase`**; `Image` only adds `Tint`. `RadiantUI_Panel.SetupPanel` constants: `BAR_SIZE=80`, `SPACING=8`, `PADDING=16`; it attaches `GenericUIContainer`+`Canvas`+scalable `Grabbable`, builds an 80px header (title + Pin/Close buttons unless userspace), content `AddFixedPadding(8,16,16,16)`. (`Text.OnAwake`/`ImageBase`/`RadiantUI_Panel.SetupPanel`)

### Physics, colliders, locomotion (`FrooxEngine`)
- **No collision groups/layers.** `ColliderType` (11 members: `NoCollision,Static,Trigger,StaticTrigger,StaticTriggerAuto,Active,CharacterController,HapticTrigger,HapticStaticTrigger,HapticStaticTriggerAuto,HapticSampler`) plus per-type byte bitmasks (`ContactMask`/`ResponseMask`/`TypeMask`) and a `CharacterCollider` bit do all filtering. (`ColliderType`)
- **`CharacterController` locomotion defaults:** Speed=4, AirSpeed=1, JumpSpeed=6, Gravity=Down·9.81, Margin=0.05, StepUpHeight=0.5, MaximumTractionSlope=45°, MaximumSupportSlope=75°. Scaling modes: Mass/Force=Cubic, Speed/Jump/Gravity=Linear. (`CharacterController.OnAwake`)
- **`Grabbable.OnAwake` sets `ReparentOnRelease`/`PreserveUserSpace`/`DropOnDisable`/`Receivable`=true**; `Scalable`/`AllowSteal`/`EditModeOnly`/`DestroyOnRelease`/`GrabPriority` default false/0. `Grab()` reparents under the grabber's `HolderSlot`, recording `_lastParent`(+userspace flag) for release restore. (`Grabbable.OnAwake`/`Grab`)
- Locomotion modules subclass `LocomotionModule : UserRootComponent`; the active set is `LocomotionController.LocomotionModules` (cycled via `NextLocomotionModule`), gated by `LocomotionPermissions`. (`LocomotionController`)

### Misc data types & limits
- **`Elements.Core.colorX`** = linear `color baseColor` + a `ColorProfile` tag; arithmetic is profile-aware (`ColorProfileHelper.GetOperands`, default `LinearIfUnequal`); comparison ops return per-channel `bool4`. Has named statics, HDR helpers (`NormalizeHDR`/`ConstructHDR`), HSV setters, hex IO, blend modes. (`colorX`)
- **`Elements.Core.BoundingBox`** = `float3 min/max` (single precision); rich API: factories (`CenterSize`/`CenterRadius`/`FromPoints`/`FromBoundingSphere`), `Encapsulate`/`Expand`/`Transform(float4x4)`/`Intersects`/`Contains`, indexed vertex/edge/face accessors. (`BoundingBox`)
- **`Elements.Core.VersionNumber`** = `Year.Month.Day.Minute` where Minute=`hour*60+min` (`MAX_MINUTES=1440`); `IsValid` requires Year≥2016 and UTC not >1h in the future; `Parse` needs exactly 4 dot parts. (`VersionNumber`)
- **`AI_GeneratedContent`**: `Source` clamped to `MAX_SOURCE_LENGTH=128`; emits item tags `ai_generated_content` and `ai_source:<source>`. (`AI_GeneratedContent`)

### Data feeds, settings, inventory
- **`IDataFeed`** is an async-enumerable browseable model: `Enumerate(path, groupKeys, searchPhrase, viewData) → IAsyncEnumerable<DataFeedItem>`, `ListenToUpdates`, `PathSegmentName`. The Settings UI is itself a feed (`SettingsDataFeed`). `DataFeedItem` subclasses are the UI vocabulary (Category/Group/Grid/Label/Indicator/Action/Toggle/Enum/Slider/ValueField/Selection/Entity…), each with `ItemKey`/`Path`/`GroupingParameters`/`SubItems`; `DataFeedItemChange{Added,Updated,Removed,PathItemsInvalidated,PathSortingInvalidated,Unchanged}`. (`IDataFeed`/`DataFeedItem`)
- **`SettingManager`** stores settings as a recomputed `SettingComponent` slot tree keyed by `SettingSwitchValue` switches; lazily recomputed when `_settingsDirty`. Exposes `UserspaceOnly`/`IsSupressed`; `SettingComponent<T>` supports `CreateOverride`/`ResetToDefault`/`CanResetToDefault`. (`SettingManager`/`SettingComponent\`1`)
- **`InventoryItem.Unpack`** saves only **rotation + scale** (`SavedRotation`/`SavedScale`/`RelativeToUserRoot`), **not position**: when not keeping position it converts saved R/S through `LocalUserRoot` (if `RelativeToUserRoot`) else applies as absolute global, then **destroys its own slot** and returns the first child. `keepExistingPosition=true` resets each child to identity. (`InventoryItem.Unpack`)
